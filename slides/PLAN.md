# RentSettle — Deck Plan

## Project
**RentSettle**: ODR platform for Bangalore tenants and landlords resolving security deposit disputes using Karnataka Rent Act rules.

## Deck
- **File**: `slides/rentsettle-deck.html`
- **Style**: Citrus Punch (Bricolage Grotesque + Plus Jakarta Sans)
- **Colors**: Warm cream base `#fff8f0`, saffron-orange `#e85d04`, indigo `#3730a3`
- **Navigation**: Arrow keys + click + nav dots

## Slide Breakdown

| # | Title | Content |
|---|---|---|
| 1 | Title | Tagline, subtitle, tech pills, live demo badge |
| 2 | The Problem | 3 stat cards (68%, 14mo, ₹2L) + 3 pain cards (tenants, landlords, proptech) |
| 3 | How It Works | 3 feature cards (rule engine, gap visualizer, PDF) + 5-step flow |
| 4 | Live Demo | Video placeholder, demo flow pills |
| 5 | Why It Wins | 5 judging criteria cards (30/25/20/15/10%) |
| 6 | Team Close | Brand close, tagline, tech stack pills |

## Demo Script (for narration)
1. Title slide — establish the product name and tagline
2. Problem slide — hit the stats (68% → 14 months → ₹2L)
3. How It Works — walk the 5-step flow quickly
4. Demo placeholder — switch to live app (`npm run dev`)
5. Why It Wins — call out each criterion and point to where judges can see it
6. Team close — brand + "watch the demo"

## Judging Criteria → Slide Mapping
| Criterion | Weight | Slide | Visible proof |
|---|---|---|---|
| Legal accuracy | 30% | Slide 3 + 5 | Rule citations in engine + PDF |
| Dual-party UX | 25% | Slide 4 (live demo) | Tenant/landlord portals, role header |
| State machine | 20% | Slide 4 (live demo) | OPEN→ROUND_1→ROUND_2→ROUND_3→SETTLED/ESCALATED |
| Settlement PDF | 15% | Slide 4 (live demo) | PDF opens in browser with timestamps |
| Evidence workflow | 10% | Slide 3 + 5 | Evidence linked to rules, "insufficient" messages |

## Pitch Timing
- **Deck**: ~2 min (slides 1–6, quick)
- **Live demo**: ~3 min (full walkthrough: scenario load → tenant → landlord → rule engine → gap visualizer → PDF)
- **Buffer**: ~30s
- **Total**: 3 min pitch + 2 min Q&A
